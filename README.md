# Ashu Prajapati — React Portfolio

A modern, responsive React/Vite portfolio website for Ashu Prajapati.

## Included
- Responsive single-page portfolio
- Hero, About, Skills, Projects, Journey and Contact sections
- React + Vite
- Lucide icons
- No backend required

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Personalize
Open `src/main.jsx` and update:
- LinkedIn URL
- GitHub URL
- Email
- Project links
- Skills/projects if needed

The profile uses a stylized initial instead of a real photo so you can replace it with your own image later.
